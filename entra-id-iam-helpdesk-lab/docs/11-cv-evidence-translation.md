# Translating This Lab Into CV Claims

Use these claims only after the corresponding evidence exists.

## Safe claims after core Entra labs are validated

- Built and administered a Microsoft Entra ID IAM lab covering user provisioning, security-group access, joiner/mover/leaver workflows, session revocation, access verification, and audit exports.
- Processed structured IAM lab tickets with approval checks, priority/SLA targets, independent verification, and evidence-backed closure.
- Automated repeatable identity lifecycle tasks with Microsoft Graph PowerShell while preserving approval, least-privilege, and verification controls.
- Performed manual access certification by comparing actual group memberships to an approved access model and remediating stale or inappropriate access.

## Add only if actually validated

- Microsoft 365 license assignment and reclamation.
- Exchange Online mailbox/shared-mailbox permission administration.
- Native Entra Access Reviews.
- Conditional Access configuration.

## Claims to avoid

- "3 years of Entra ID administration" unless your employment history actually supports it.
- "Managed enterprise IAM" from this lab.
- "Production Microsoft 365 administrator" from this lab.
- "Implemented Conditional Access" if you only wrote the design.
- "Handled hundreds of IAM tickets" from a 15-ticket simulation.

Good portfolio language distinguishes professional experience from hands-on lab work.

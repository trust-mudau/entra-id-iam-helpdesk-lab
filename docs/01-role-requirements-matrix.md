# IAM Helpdesk Role Requirements Matrix

| Target requirement | Current portfolio evidence before this lab | Gap | Lab evidence to create |
|---|---|---|---|
| 2+ years IT support/service desk | 3 years IT support experience | Strong base | CV wording + ticket discipline |
| Microsoft 365 administration | Limited direct evidence | High | User/license/admin workflow evidence |
| Exchange Online | Limited direct evidence | High | Mailbox, forwarding/delegation runbook + lab proof |
| Active Directory / Entra ID | Security-adjacent identity concepts only | High | User/group/lifecycle administration in Entra |
| High-volume provisioning/deprovisioning | No demonstrated structured IAM queue | High | 15-ticket queue + timed batch scenarios |
| Security groups/permissions | Networking ACL/security background, not identity groups | Medium/High | Department/app groups + least-privilege matrix |
| Onboarding/offboarding | General support background | Medium/High | Full joiner/mover/leaver SOP and evidence |
| ITSM / structured tickets | No public IAM ticket evidence | High | Ticket fields, priority, SLA, approval and closure criteria |
| Access governance | Blue-team/risk background | Medium | Manual/Entra access review + orphaned access checks |
| Compliance/documentation | Strong documentation/risk orientation | Medium/Strong | Audit trail and final IAM audit report |
| Automation/process improvement | Python/security automation evidence | Medium/Strong | Microsoft Graph PowerShell lifecycle automation |
| Remote/U.S. hours | Based in South Africa | Application positioning | Explicit EDT availability statement if true |
